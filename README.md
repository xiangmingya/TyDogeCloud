# TyDogeCloud

**Typecho 多吉云附件上传与图片地址管理插件**

作者：**湘铭呀** · 当前版本：**1.2.0** · 适配：**Typecho 1.3**

使用多吉云新的简单上传接口，通过 PHP cURL 直接发送文件，无需安装 Composer 或额外 SDK。支持附件上传、替换、可选远端删除，以及统一切换域名、图片规则和比例水印。

**[多吉云地址](https://www.dogecloud.com/?iuid=5572)**

上方为作者的多吉云邀请入口。

## 1.2.0 更新：同步删除与自定义确认框

- 编辑文章、独立页面时，附件删除使用自定义中文弹窗，显示完整文件名和删除范围，默认聚焦「取消」，支持键盘操作。
- 在插件设置中将「删除附件时」设为「同步删除云端文件」，确认后同时删除附件记录与桶中的对应文件；选择保留时，弹窗会明确说明文件保留。
- 先校验附件权限，再删除云端文件；云端失败会保留当前附件记录并提示错误，成功后不重复调用删除接口。
- 弹窗只在服务端确认成功后移除附件列表项；新上传的附件也可直接使用。
- 后台常见确认入口使用统一外观，包括评论、附件管理、批量操作、自定义字段、草稿、保存预览和备份恢复，以及 TyTTS 播客稿删除；保留原有校验与提交流程。浏览器自身的安全提示、离开页面提示，以及未适配的第三方插件弹窗仍由各自管理。
- 弹窗随插件安装生效，无需修改 Typecho 核心文件或前台主题。覆盖升级后直接保存一次插件设置以注册新钩子。
- 保留站点图片流使用的缩略图方法，兼容输出钩子的重复处理。

## 1.1.0 更新：统一管理域名和图片规则

- 展示时将历史图片域名转换成当前域名，统一替换旧 `!syt?format=webp` 等处理后缀。
- 支持多吉云 `/样式名`、自定义 `!样式名` 及 `?imageView2/...`、`?imageMogr2/...`、`?watermark/...` 参数模式；多个处理动作用 `|` 串联。
- 正文、摘要和 RSS 使用内容钩子；主题页面使用输出钩子，兼容缩略图字段、广告图、懒加载图片、srcset 和 CSS 背景图片。
- 新上传返回原图地址，处理规则仅在展示时追加。以后更改规则无需改文章正文。
- 保存新域名时自动将上一次域名加入历史列表，旧正文中的图片也随之切换。
- 升级：覆盖原文件夹后打开插件设置，**直接保存一次**即可刷新插件钩子，保留已有密钥；不要先禁用，Typecho 禁用会清除插件设置。

这是一层运行时地址转换，不会改写文章、自定义字段或主题设置中的历史数据，也不会搬运云端文件。停用转换后，历史数据仍然保留原地址。请确保新域名能访问相同对象路径。

## 1.0.2 更新

## 安装和配置

1. 从仓库「发行版」下载 `TyDogeCloud-1.2.0.zip` 并解压，将整个 `TyDogeCloud` 文件夹放进站点的 `usr/plugins/`，确认入口是 `usr/plugins/TyDogeCloud/Plugin.php`。若使用 GitHub 源码压缩包，请将解压目录重命名为 `TyDogeCloud`。
2. 停用 TyUpyun、UpyunFile 及其他接管附件上传的插件，再启用 TyDogeCloud。
3. 在插件设置填写以下内容：

| 设置 | 填写内容 |
| --- | --- |
| 存储空间名称 | 多吉云控制台中的 Bucket 名称，不是域名或空间 ID |
| AccessKey / SecretKey | 多吉云用户中心 → 密钥管理中的永久密钥 |
| 文件访问域名 | 填写自己的访问域名，例如 `https://img.example.com`；不要包含路径或文件名 |
| 存储路径前缀 | `typecho/uploads` |
| 旧附件路径映射 | 文件已迁移到相同年月目录时开启；默认开启 |
| 删除附件时 | 默认保留云端文件，可手动开启同步删除 |
| 展示时统一图片地址 | 默认开启；开启后以下历史域名和图片规则会在页面展示时生效 |
| 历史图片域名 | 每行一个旧域名，请替换预填的作者站点示例；第三方域名不会转换 |
| 多吉云图片处理规则 | 默认留空显示原图；按下面的示例填写 |

插件预填的 `img.xiangming.site`、`yop.xiangming.site` 是作者站点示例，安装后请换成自己的域名。然后在 Typecho 写文章页面使用原来的附件上传按钮即可。图片及其他允许类型的附件都经新接口上传，示例地址：

```text
https://img.example.com/typecho/uploads/2026/11/随机文件名.png
```

运行环境需启用 PHP `curl`，`fileinfo` 为可选扩展。若提示缺少 cURL，请在宝塔“网站 → 博客站点 → PHP 版本”确认实际版本，再到“软件商店 → 对应 PHP → 设置”启用 cURL；不要只检查命令行 PHP。PHP 的 `upload_max_filesize`、`post_max_size` 和 Web 服务器请求大小限制也须允许你的上传大小。密钥只存储在 Typecho 服务端插件配置中，请限制后台和数据库访问权限。

## 图片规则怎么填

| 需求 | 插件中填写的规则 | 输出示例 |
| --- | --- | --- |
| 显示原图 | 留空 | `https://img.xiangming.site/typecho/uploads/2026/10/2735706219.png` |
| 控制台配置的样式 | `/syt` | `…/2735706219.png/syt` |
| 按宽度缩放并转 WebP | `?imageMogr2/thumbnail/1600x/format/webp` | `…/2735706219.png?imageMogr2/thumbnail/1600x/format/webp` |
| 自定义 `!` 分隔符 | `!syt` | `…/2735706219.png!syt` |

使用样式前，需要在**标准型存储空间 → 图片处理**中开启功能，创建对应规则；样式中可以配置水印、缩放和输出格式。多吉云默认分隔符为 `/`，`!` 分隔符需要客服联系配置，不能照搬又拍云的后缀。规则名称使用字母、数字、下划线或短横线。

参数模式需要使用自定义 CDN 域名，并关闭缓存规则中的“忽略参数”。多个处理步骤用 `|` 串联，不要另加 `&format=webp`；转换格式放进 `imageMogr2/.../format/webp` 或控制台样式里。多吉云控制台新规则可能需 5–20 分钟生效，插件不能替代云端规则配置。尚未配置时请留空显示原图。

更换域名：直接修改“文件访问域名”并保存；原域名会自动加入历史列表。新域名下仍需能访问相同图片文件。若整页被 CDN 或缓存插件缓存，需要清除页面缓存后查看新输出。

### 按原图面积缩放水印

固定像素水印在小图上会显得更大。可以用下面的比例规则，让水印随原图大小一起缩放：

```text
?watermark/1/image/水印地址的URLSafeBase64编码/gravity/south/dx/0/dy/10/dissolve/85/scatype/3/spcent/3|imageMogr2/format/webp
```

**请将占位文字替换为自己的水印图片地址编码，不能直接复制占位文字使用。** 水印图片必须能被多吉云读取，建议使用透明 PNG。可用 PHP 生成编码：

```php
echo strtr(base64_encode('https://img.example.com/watermark.png'), '+/', '-_');
```

| 参数 | 说明 |
| --- | --- |
| `gravity/south` | 底部居中 |
| `dx/0/dy/10` | 横向偏移 0，底部边距 10 像素 |
| `dissolve/85` | 水印透明度参数为 85 |
| `scatype/3` | 按原图整体面积缩放 |
| `spcent/3` | 水印面积为原图的千分之三，即 **0.3%**，不是 3% |

方形水印在 1188×697 的示例图上约为 **50×50**；在 300×176 的示例图上约为 **13×13**。这里的 50×50 是示例尺寸，并非每张图固定使用该尺寸。水印缩放时保持长宽比。

修改 `spcent` 可以调整面积占比，具体范围与其他参数见[多吉云图片水印规则](https://docs.dogecloud.com/mps/dev-rule-watermark)。更换水印后若仍使用相同图片地址，请刷新相关 CDN 缓存。

## 接口实现

- 上传：`PUT https://api.dogecloud.com/oss/upload/put.json?bucket=…&key=…`，请求正文直接发送文件二进制，不是 multipart 表单。
- 签名：`TOKEN AccessKey:HMAC-SHA1(SecretKey, REQUEST_URI + "\n" + "")`，使用十六进制结果。包含经过 RFC 3986 编码的实际查询参数；**PUT 不把文件正文加入签名**。
- 替换：对原 Bucket / Key 再次 PUT，保留附件地址；CDN 可能继续缓存旧内容，需要等待缓存过期或在多吉云刷新缓存。
- 删除（可选）：`POST /oss/file/delete.json?bucket=…`，正文为 `["文件Key"]`，签名中包含这段 JSON 正文。
- 同时检查 HTTP 状态和响应 JSON 的 `code === 200`；网络、鉴权或 API 错误不会被当作上传成功。错误写入 PHP 日志，前缀为 `[TyDogeCloud]`，不会记录密钥或响应原文。
- 有 fileinfo 时按文件内容识别 MIME；缺少时识别图片，其他类型交给多吉云。保留 Typecho 的附件扩展名白名单。
- HTTPS 请求启用证书验证，不自动跟随 API 重定向。

官方简单上传接口仅支持 **10MB 以内**文件，每用户 **10,000 次/天**。插件按 10 MiB（10 × 1024 × 1024 字节）设置本地上限，服务端仍以多吉云限制为准；超限需改用 S3 上传，本插件不调用旧版上传 Token 接口。

## 旧文件和使用边界

- 默认映射 `/usr/uploads/2026/10/2116638127.png` → `typecho/uploads/2026/10/2116638127.png`，对应已配置的访问域名。自定义 `__TYPECHO_UPLOAD_DIR__` 时按该目录映射。
- 旧附件路径映射用于 Typecho 附件地址；“展示时统一图片地址”还会处理正文和主题页面里的历史链接。两者都不会搬运文件或修改数据库原文。
- 新附件会记录实际 Bucket / Key，之后修改前缀或默认 Bucket 不会把已有新附件的替换、删除操作指向新位置。旧附件没有这类元数据，依赖当前映射配置。
- 关闭旧附件映射后，旧附件使用 Typecho 本地地址；本插件不会替换或删除这些旧文件。若旧文件曾使用其他云插件，应先安排迁移和地址更新。
- 同步删除默认关闭，需要在设置中明确开启。开启后，已映射的旧附件也属于删除范围；文件删除后无法恢复，引用它的内容可能失效。插件通过前置钩子先完成云端删除，失败时保留当前附件记录并中止该次操作。批量删除若中途失败，此前已经成功删除的文件不会恢复。
- 删除云端源文件不会自动刷新 CDN 缓存，旧链接可能暂时仍可访问；需要立即失效时，请在多吉云控制台刷新相关缓存。
- 停用插件会失去动态云端地址映射，云端对象仍保留。切换前应安排接替插件或链接迁移。
- 转换只应用于历史列表和当前域名下的图片 URL；SVG/ICO 只换域名，不追加位图处理规则。不修改第三方链接或 PDF、视频等非图片资源。新上传的非图片附件仍走正常上传流程。JSON 中反斜杠转义的地址、前端脚本运行后才拼出的地址，以及绕过 Typecho 模板的独立 API 不在整页转换范围内；自定义输出可调用 `TyDogeCloud_Plugin::rewriteHtml($html)`。

```sh
TYPECHO_ROOT=/你的路径/typecho php tests/integration.php

```

检查需要 PHP cURL 和 PDO SQLite 扩展，离线验证签名和上传、原生设置入口、缺少 fileinfo 时的兼容、历史 URL/样式/参数转换、重复转换、第三方隔离、原生正文/RSS/主题输出钩子，以及 SQLite 下升级注册和历史域名保存。还会运行 Typecho 原生删除流程，确认云端失败时保留记录、无权限时不删除、成功时只发出一次请求。使用模拟请求和内存数据库，不调用真实云接口，也不需要真实密钥。
